# Autonomous Agents

A learning and research repository for building autonomous agent systems. Currently exploring Claude Agent SDK and Google Antigravity.

This project serves as a workspace for exploring multi-agent architectures, agent skills, and agentic workflows. It includes documented examples, skeleton models, and implementation patterns for reference when creating new agents.

## Purpose

- Explore autonomous agent design patterns
- Document step-by-step agent construction
- Maintain reusable agent skeletons and templates
- Research agent capabilities and limitations
